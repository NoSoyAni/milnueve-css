## ⚡ Descripción General

Este repositorio contiene **dos archivos CSS** diseñados para inyectarse en el sitio web de **Milnueve**, reemplazando la interfaz tradicional por un entorno visual futurista inspirado en sistemas **HUD (Heads-Up Display)**.

* **Efectos de Neón y Contraste:** Estética cibernética con tonos oscuros y acentos cian/cian brillante.
* **Layout Reorganizado:** Paneles delimitados y bordes limpios para mejorar la legibilidad y la navegación.
* **Carga Ligera:** Modificación visual nativa mediante hojas de estilo sin impacto en el rendimiento.

---

## 📂 Archivos del Proyecto

| Archivo | Descripción | Estado |
| :--- | :--- | :---: |
| `milnueve-hud-base.css` | Reestructuración de layout, paleta de colores oscuros y tipografía base. | `75%` 🟡 |
| `milnueve-hud-effects.css` | Efectos visuales avanzados, bordes luminosos tipo HUD y overlays. | `40%` 🔴 |

---

## 🚀 Instalación y Uso

Puedes aplicar estas hojas de estilo utilizando cualquier extensión de navegador para estilos de usuario (como **Stylus** o **UserCSS**):

1. Instala la extensión **Stylus** en tu navegador.
2. Crea un nuevo estilo para el dominio de Milnueve.
3. Importa o copia el contenido de los dos archivos CSS:

```css
/* Importación directa */
@import url('https://raw.githubusercontent.com/TU-USUARIO/TU-REPOSITORIO/main/milnueve-hud-base.css');
@import url('https://raw.githubusercontent.com/TU-USUARIO/TU-REPOSITORIO/main/milnueve-hud-effects.css');
```
